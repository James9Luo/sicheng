# 场景 1：SVG 设计审稿与优化

## 工作流程

### 步骤 1：接收 SVG 设计

- 从 `idea/` 目录读取用户提供的 SVG 设计文件
- 检查文件格式和完整性

### 步骤 2：设计分析

从以下维度分析 SVG 设计：

| 维度 | 评估内容 |
|------|----------|
| **设计美学** | 视觉平衡、层次感、色彩搭配、整体风格一致性 |
| **实用性** | 信息可读性、布局合理性、交互友好性 |
| **技术可行性** | 是否符合 Zepp OS 表盘规范、是否能转换为实际实现 |
| **设备适配** | 是否适配目标设备（如 T-Rex 3）的屏幕规格 |

### 步骤 3：问题清单及修改建议

- 列出发现的设计问题
- 提供针对性的修改建议

### 步骤 4：表盘设计布局方案

输出完整的表盘设计布局方案模板到`design/`目录

## 常见问题及建议

```
问题：刻度线过于密集
建议：精简为小时标记 + 主要半小时标记

问题：文字与背景对比度不足
建议：增加描边或阴影提高可读性

问题：布局超出安全区域
建议：确保内容在屏幕可视范围内
```
